สรุปรายโครงการ

EAC = ประมาณการต้นทุนเมื่อจบโครงการ · Variance = Budget − EAC (บวก = ต่ำกว่างบ) · ต้องจ่ายอีก = EAC − จ่ายแล้ว

งบถูกใช้ไปถึงไหน ตามหมวด (Task L1)

Contingency

ใช้ไป = ผลรวมส่วนที่ EAC เกินงบของทุก Cost Code (ไม่หักกลบกับรายการที่ต่ำกว่างบ)

ต้นทุนตามหมวด Task L1 → L2 → Cost Code

Committed = PO + จ่ายตรง (ไม่รวม Estimate) · ค้างจ่าย = Invoice ที่ยังไม่จ่าย · แผนคงเหลือ = งวดใน EXP_Plan ที่ยังไม่มี Invoice · แท็ก เกินงบ เกิน PO

Cash Flow — เงินจ่ายรายเดือน

จ่ายแล้วค้างจ่าย (มี Invoice) แผนจ่าย (ยังไม่มี Invoice)ยังไม่มีแผน (ตามงบ)

S-Curve สะสม

จ่ายแล้วสะสมคาดการณ์สะสม Budget (ไม่รวม Contingency)EAC

ค้างจ่าย (AP Aging)

Invoice ที่ได้รับแล้วยังไม่จ่าย (ยอดสุทธิรวม VAT) แยกตามวันที่เกิน Due Date

กำหนดจ่าย 60 วันข้างหน้า + เลยแผน

รวม Invoice ค้างจ่าย และงวดตามแผนที่ถึงเดือนจ่าย (ไม่รวม VAT) · เลยแผน = ถึงเดือนแล้วแต่ยังไม่มี Invoice

PO / Commitment Detail
